# 钉笺

一个可移动、可缩放、可收进 Mac 桌面右侧的轻量便签，包含日历、日程、视频选题排期、待办与番茄计时。它位于桌面图标之上、普通窗口之下，不会盖住正在工作的窗口。

## 当前决定

- 先做原生 macOS 本地版，不加账号、云同步和复杂分类。
- 核心任务是“把今天要做的事贴在桌面上，并留下真实用时”。
- 窗口位置和尺寸由使用者决定；切换板块、进入编辑或贴回桌面都不得擅自移动或缩放窗口。
- 数据、计时进度、主题、透明度和自定义背景都保存在本机。
- 视觉采用蓝白卡片，以顶部蓝色计时器为唯一高饱和重点，日历、日程和待办保持清晰层级。

## 构建与运行

```bash
./build-app.sh
open "dist/钉笺.app"
```

系统要求：macOS 13 或更高。
应用使用 Objective-C + AppKit 实现，Apple 日历同步使用 macOS 自带的 EventKit，不依赖第三方运行库。

## 本地打包与分享

执行：

```bash
./package-local.sh
```

会同时生成 `dist/钉笺-macOS-0.14.3.dmg` 和 `dist/钉笺-macOS-0.14.3.zip`。优先把 DMG 发给 Mac 用户：双击打开后，将 `钉笺.app` 拖入“应用程序”。ZIP 作为备用，应先保存到 Mac 本机的“下载”或“桌面”再解压，不要在微信、网盘或只读磁盘中直接打开。当前安装包采用临时本地签名，适合自己测试或发给少量已知测试者；对方第一次打开时可能需要在 Finder 中右键应用并选择“打开”。

## 隐藏后怎么打开

应用隐藏后不会退出。点击 macOS 顶部菜单栏里的清单图标，可选择：

- `显示主面板`
- `开始 / 暂停专注`
- `显示全部`

菜单栏里也可以直接新增待办、贴回桌面或退出应用。

正式公开分发仍需要 Apple Developer Program 的 Developer ID Application 证书，并在完整 Xcode 工具链下完成 hardened runtime、签名、公证和 stapling。当前机器没有可用的 Developer ID 身份，因此这一版没有冒充“已可无提示公开安装”。

## 数据位置

- 待办、日程、视频选题和计时：`~/Library/Application Support/PinnedNote/data.json`。
- 自动备份：`~/Library/Application Support/PinnedNote/Backups/`。
- 窗口、主题等设置：macOS `UserDefaults`，bundle id 为 `com.firehua.pinnednote`。
- 自定义背景：`~/Library/Application Support/PinnedNote/`。
- 当前没有账号与云同步；把应用发给别人不会连带发送你的待办或背景图片。
